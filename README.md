# Вокзали України — залізнична енциклопедія

Навчальний вебпроєкт українською мовою. Статичний сайт із динамічним завантаженням даних OpenStreetMap.

## Запуск
Відкрийте `index.html` у браузері або увімкніть GitHub Pages у налаштуваннях репозиторію (Settings → Pages → Deploy from a branch → main → /(root)).

## Розділи
- Каталог вокзалів, залізничних станцій і зупинних пунктів України.
- Пошук, фільтри та сортування за назвою, віком, площею й пасажирообігом.
- Сторінка окремого об'єкта з описом, картою та доступними характеристиками.
- Рейтинги, депо, мапа та історія.
- Адаптивний інтерфейс для телефонів і комп'ютерів.

## Дані станцій
Початкові приклади розміщені у `data.js`. Під час відкриття сайту `app.js` завантажує об'єкти з OpenStreetMap через Overpass API: `railway=station` та `railway=halt` у межах України. Міські трамвайні й метро-зупинки не включені до цього каталогу. Об'єкти без назви або координат пропускаються; дублікати за назвою та близькими координатами прибираються.

OpenStreetMap — відкрита картографічна база, яку наповнюють користувачі. Це не офіційний реєстр Укрзалізниці, тому покриття може бути неповним, а частина записів — потребувати уточнення. Для кожного імпортованого об'єкта є посилання на його запис OSM. Для коректної атрибуції використовуйте формулювання «© OpenStreetMap contributors» та дотримуйтеся ліцензії ODbL.

Значення року побудови, площі, кількості платформ і колій, пасажирообігу та депо не вигадуються: невідомі поля показуються як «Потребує уточнення».

## Якщо перелік не завантажується
Потрібне підключення до інтернету та доступність одного з Overpass API серверів. Якщо сервер тимчасово недоступний, сайт покаже початкові приклади зі `data.js`.
