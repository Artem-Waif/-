# Вокзали України — залізнична енциклопедія

Навчальний вебпроєкт українською мовою. Статичний сайт без серверної частини та сторонніх JavaScript-бібліотек.

## Запуск
Відкрийте `index.html` у браузері або увімкніть GitHub Pages у налаштуваннях репозиторію (Settings → Pages → Deploy from a branch → main → /(root)).

## Розділи
- Каталог вокзалів із пошуком, сортуванням і фільтрами.
- Сторінка окремого вокзалу з описом, характеристиками, картою та блоком статистики.
- Рейтинги, депо, мапа та історія.
- Адаптивний інтерфейс для телефонів і комп'ютерів.

## Дані
Основний набір розміщено у `data.js`. Додайте новий об'єкт до масиву `STATIONS`, використовуючи наявні поля. Значення `null` відображаються як «Потребує уточнення». Не заповнюйте статистику припущеннями: використовуйте перевірені джерела та зазначайте дату й методику підрахунку.

## Важливо
Фотографії завантажуються із зовнішнього фотосервісу та можуть змінюватися. Для публічного використання замініть їх на власні або належно ліцензовані зображення. Мапа використовує OpenStreetMap.
